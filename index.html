Experiência Profissional

Desenvolvedor Full Stack – Sistema de Gestão Administrativa

Fiz parte do desenvolvimento e manutenção de um sistema de administração empresarial, utilizando Node.js 21.7 com NestJS no back-end e Angular 16 no front-end. O sistema contemplava módulos de controle de agenda, gestão de parcelas, cadastro de parceiros , relatórios gerenciais, dashboards e etc.

Fiz parte da integração com APIs externas de pagamento, implementando suporte a Pix, boleto bancário e cartão de crédito, além de uma API de geração e gerenciamento de contratos, garantindo o fluxo completo de assinatura e armazenamento de documentos pela S3.

Node.js NestJS Angular 16 API REST Pix / Boleto / Cartão API de Contratos TypeScript S3 Postgresql Migrations Git GitHub
